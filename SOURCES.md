# Source Datasets and Attribution

SEV-Change contains derivative question records based on two existing datasets. The original data owners retain their respective rights. The image files are not copied into this package.

## RSRCC

- Official dataset: [google/RSRCC on Hugging Face](https://huggingface.co/datasets/google/RSRCC)
- Official project repository: [google-research/remote-sensing](https://github.com/google-research/remote-sensing)
- Official paper record: [arXiv:2604.20623](https://arxiv.org/abs/2604.20623)
- Dataset page license label: `apache-2.0` (verify scope before assigning a license to derivative annotations).

The official dataset page provides this paper citation: R. Kazoom, Y. Gigi, G. Leifman, T. Shekel, and G. Beryozkin, “RSRCC: A Remote Sensing Regional Change Comprehension Benchmark Constructed via Retrieval-Augmented Best-of-N Ranking,” arXiv:2604.20623, 2026.

## DisasterM3

- Official project repository: [Junjue-Wang/DisasterM3](https://github.com/Junjue-Wang/DisasterM3)
- Official paper record: [arXiv:2505.21089](https://arxiv.org/abs/2505.21089)
- Repository terms: imagery and associated annotations are for academic use only; commercial use is prohibited.

The official repository gives this citation: J. Wang, W. Xuan, H. Qi, et al., “DisasterM3: A Remote Sensing Vision-Language Dataset for Disaster Damage Assessment and Response,” Proceedings of the Neural Information Processing Systems, 2025.

Users of SEV-Change should cite the original dataset corresponding to every subset they use. Add the verified SEV-Change paper and dataset DOI citation once those exist.
