# Licensing Status and Source Terms

No onward reuse license grant is asserted for the SEV-Change derivative annotation files in this public candidate package. The uploader confirmed on 2026-09-23 that they have the right to redistribute the included DisasterM3-derived questions, answers, and associated fields. This is an uploader attestation, not an independently verified upstream license. The absence of a `LICENSE` file is intentional while the precise downstream grant is being decided. This document records source terms; it is **not** a replacement license.

The package contains no source images, but the JSON files retain source questions, answers, options, and image-path references. Therefore the source terms remain relevant to the annotation release. The DisasterM3 repository also lists CC BY-NC-SA 4.0 for xBD and CC BY-NC 4.0 for BRIGHT as underlying datasets; those are upstream notices, not an express license for the entire DisasterM3 dataset.

Before a final release, record the exact downstream license identifier, license text, attribution requirements, and legal basis here and in `DATASET_CARD.md`. Code can be licensed separately once its owner chooses a code license. Public availability alone must not be interpreted as permission for commercial reuse.
